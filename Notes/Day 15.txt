	• Data Binding
		What is Data Binding?
			Data binding is a software programming technique that connects a user interface (UI) element to a data source (like a variable, object, or database). It automatically synchronizes the two, meaning any updates made to the data are immediately reflected in the UI, and vice versa, without requiring manual code to update the screen
		Why is it used?
			Before data binding, developers had to write repetitive code to manually fetch data from a source and push it into a UI component (e.g., pulling a user's name from a database and writing code to display it inside a text box). Data binding abstracts this process, which significantly reduces the amount of code needed, minimizes bugs, and makes the application much easier to maintain.
		What is Angular Data Binding?
			Data binding is a technique, where the data stays in sync between the component & the template.

	• Angular Directives
		What are Angular directives?
			The angular Directive delps us to manipulate DOM. You can change the appearance, behavior, or layout of a DOM element using them.
		Types Of Directives in Angular
			Component Directives
				Components are special Directives in Angular with a Template(view).
			Structural Directives
				Structural Directives can change the DOM layout by adding and removing DOM elements.
					*ngFor
					*ngSwitch
					*ngIf
			Attribute Directives
				ngModel
				ngClass
				ngStyle
