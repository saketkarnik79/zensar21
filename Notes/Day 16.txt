Component Life Cycle Hook
	• Component Life Cycle
		What are Angular Component Lifecycle hooks?
			Angular lets us know when the lifecycle events happen using the lifecycle hooks. In practice, these lifecycle hooks are callback function, which angular invokes when a specific event occurs during the component's lifecycle.
		Types of hooks
			ngOnChanges
			ngOnInit
			ngDoCheck
			ngAfterContentInit
			ngAfterContentChecked
			ngAfterViewInit
			ngAfterViewChecked
			ngOnDestroy

Services & Dependency Injection
	• Services
		What is An Angular Service?
			Service is a piece of reusable code with a focused purpose.
		What Angular Service are used for?
			Features that are independent of components, such as logging services.
			Share logic or data across components.
			Encapsulate external interactions like data access.
